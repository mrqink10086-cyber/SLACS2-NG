# SLACS2 NG 1.0.7 游戏实测记录

日期：2026-11-11。来源：用户在本次会话转交的测试者反馈及两张截图；测试者明确标注 1.0.7，界面显示 Skyrim 1.6.1170。此记录按反馈与画面确认测试范围。

## 已游戏实测

- 测试角色为 NPC 卡萝塔·巴伦西亚。
- 中文菜单与依赖状态可显示，测试加层可操作；截图包含一层及达到五层上限后的状态。
- 身体存在可见覆盖痕迹，手臂也可见痕迹；测试者反馈“目前使用 OK”。菜单五层计数与核心逻辑达到上限的诊断可见。

## 已发现问题

Face 一层时有可见痕迹，但增加到五层后未呈现预期的多层视觉叠加。菜单的五层计数代表逻辑状态，不能单凭计数确认五个面部覆盖节点都正确渲染。用户回忆原 Papyrus 版本也有类似表现，需对照旧脚本、纹理和 RaceMenu 面部材质路径调查。

## 尚待分别验收

- P+ 自动事件加层及多人、tid 复用和异步取消。
- 七个区域逐项检查、26 个装备效果组合逐项检查及效果开关清除。
- 换装、3D 重建、读档、连续换档与配置重启保持。
- 与 SlaveTatsNG 共存、长时间稳定性及实机性能预算。

两张静态截图不能单独区分装备上的白色来自 EFSH 还是覆盖层，也不能验收换装重绑与读档恢复。因此这些独立项目保留后续测试状态，版本整体标记为“已有游戏实测反馈”。
