# SLACS2 NG 纹理包 1.0

文件名：`SLACS2NG-Textures-1.0.zip`。这是独立于程序版本的基础纹理包，供 SLACS2 NG 1.0.7 及后续声明兼容本纹理包的程序使用。

## 安装

1. 将 ZIP 直接拖入 MO2，或使用“从压缩包安装”，作为独立模组安装并启用；无需预先解压。
2. 再安装并启用 `SLACS2NG-Main-1.0.7.zip` 或后续兼容程序包，保留两项同时启用。
3. 以后更新程序时只替换 Main 模组，保留 Textures 模组。只有贴图资源变化并发布新纹理版本时，才更新本包。

压缩包根目录直接是 `Textures/` 和 `Docs/`，对应游戏 `Data` 目录内的内容。手动安装时，将它们合并到游戏的 `Data` 目录。说明与 SHA-256 清单位于 `Docs/SLACS2NG/textures/`。

## 内容

- 七区域普通与 Mega 贴图共 264 张 DDS。
- `Textures/slacs2/clothes/` 下 26 张装备效果组合贴图。
- 合计 290 张 DDS，不含 DLL、ESP、脚本或设置。

早期完整包和升级包遗漏了 26 张 `clothes` 贴图；已有这些旧包的用户也需安装本纹理包。程序更新无需重复下载这些资源。
